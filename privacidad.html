Política de privacidad de Claude MCP

Última actualización: 1 de noviembre de 2026.

Qué datos usa

Con el permiso de Google Calendar que autoriza su autor, la aplicación puede leer, crear, editar y eliminar eventos de sus calendarios. No solicita acceso a ningún otro dato de Google.

Dónde se guardan

La credencial de acceso se guarda solo en el computador del autor. La aplicación no tiene servidores ni bases de datos propias.

Con quién se comparten

La información de los eventos que se consulta durante una sesión se envía a Claude, de Anthropic, para responder las solicitudes del autor. No se vende, no se usa para publicidad y no se comparte con nadie más.

Uso limitado

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El permiso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
